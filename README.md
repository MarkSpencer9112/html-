# GraphWar：数学函数炮战

一个基于 HTML5 Canvas 的单页数学函数炮弹游戏。玩家需要观察二维坐标系中敌人的视觉位置，输入函数规划曲线弹道，而非使用传统准星直接瞄准。

## 启动

项目没有第三方依赖或构建步骤，直接在浏览器打开 `graphwar.html` 即可。

若浏览器对本地 ES Module 有限制，可在项目目录启动静态服务器：

```bash
python3 -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/graphwar.html`。

## 核心玩法

- 战场是同时包含正、负坐标的二维笛卡尔坐标系，具有 X/Y 轴、原点、网格及刻度。
- 玩家和敌军会在地图的不同位置随机生成，并保持合理距离。
- 敌军仅通过地图中的视觉标记呈现；UI 不会显示其精确坐标或距离。
- 每个玩家回合为 60 秒。输入函数后可先预览，再发射。
- 炮弹从玩家位置出发，严格沿函数曲线飞行；离开有效地图或命中后结束攻击。
- 敌军 AI 使用同样的函数弹道机制，但目标估计包含随机误差。

## 函数与坐标规则

输入的函数以发射者为局部原点：

```text
世界 y = 发射者 y + f(发射方向 × (世界 x - 发射者 x))
```

例如 `x^2` 会从玩家炮台向前形成向上弯曲的抛物线。敌军向左发射时，也会使用相同的局部函数逻辑。

输入框支持以下形式：

```text
x^2
y=x^2+2x-3
f(x)=sin(x)
2x+5
```

支持的运算和函数：

- 运算：`+`、`-`、`*`、`/`、`^`，以及隐式乘法（如 `2x`、`2(x+1)`）
- 函数：`sin(x)`、`cos(x)`、`tan(x)`、`abs(x)`、`sqrt(x)`、`log(x)`、`ln(x)`、`exp(x)`
- 常量：`pi` 或 `π`，以及 `e`

## 导数攻击

函数类型按钮可选择：

- `f(x)`：原函数曲线
- `f'(x)`：一阶数值导数曲线
- `f''(x)`：二阶数值导数曲线

例如输入 `x^3` 并选择一阶导数时，弹道等价于沿 `3x^2` 运动。导数由中心差分数值计算，便于后续支持更多函数。

## 命中与伤害

单位和炮弹都具有碰撞半径，不需要让函数严格经过敌人中心。

- 直接命中：最高伤害
- 近距离命中：中等伤害
- 擦边命中：较低伤害

HP、碰撞半径、伤害档位、地图范围、动画时长和 AI 误差等平衡参数统一配置在 `graphwar-core.js` 顶部的 `CFG` 中。

## 代码模块说明

`graphwar-core.js` 内部按职责划分：

- `MathExpressionParser`：词法解析、表达式求值、非法输入处理及一、二阶数值导数。
- `Coord`：数学坐标与 Canvas 像素坐标互转。
- `trajectory()`：把局部函数转换为以单位位置为起点的世界弹道。
- 回合控制：玩家输入阶段、敌方 AI 阶段、倒计时与胜负判定。
- 碰撞与伤害：基于炮弹半径和单位半径的距离判断，以及分级伤害。

## 输入错误

不合法表达式（例如 `x^^2`、缺失括号或不支持的函数）不会中断游戏，会在界面中显示“函数解析错误”。
